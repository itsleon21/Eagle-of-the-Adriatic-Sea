# 施耐德杯·亚德里亚纪念赛（建议，尚未实现）

定位为独立的水上竞速赛事，保留自由飞行和现有五航点挑战。采用三角形绕标个人计时赛，优先让玩家体验高速切弯和保速。

- 练习单圈；标准赛三圈，每圈约9–12km，MC.72总赛程约4–6分钟；七圈经典长度作为后续选项。
- 水面集结、倒计时起飞、穿越空中计时门开始比赛、三座大转向标逐圈绕行、冲线结算。着水回港作为独立返航目标，不影响冲线成绩。
- 转向标采用浮标/旗门与宽裕绕标区，按MC.72当前转弯半径留350–500m空间。使用移动线段、方向与顺序检查，漏标必须补绕；提示建议飞行高度60–150m。
- MC.72竞速组、红翼公开组独立纪录；M5更适合观光拉力。计时比赛关闭X/Z辅助特技，避免辅助轨迹影响公平性。
- 首版固定晴天、轻风和时刻，暂停不计时；提供分段时间、最佳圈、与个人最好成绩的差值。随后加入本地个人幽灵机，最后再做AI对手。
- 场景增加起终点浮台、观赛船、转向塔、旗帜和奖杯。比赛期间通航船只绕开赛道/起降水域，避免随机船流影响成绩。

建议分三次交付：一圈可玩赛道与绕标判定 → 三圈计时及结算/分组纪录 → 个人幽灵机与赛事氛围。当前版本没有启动比赛开发。

历史说明：1925年官方赛事资料记载了三角赛道。MC.72为1931赛事研制但没有实际参加该届竞赛，红翼为游戏虚构机型，因此建议称作纪念赛而非严格历史复刻。
