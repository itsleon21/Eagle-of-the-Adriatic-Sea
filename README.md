# 亚德里亚之鹰 Eagle of the Adriatic

一款桌面浏览器单机飞行探索游戏。在机库选择红翼一号、M5战斗飞艇或马基MC.72，从港口滑跑起飞，探索亚德里亚风格的群岛，完成五航点环岛挑战，再返回海面着水。

当前交付为 **v0.28**。在珊瑚岛栈桥附近可选择进入独立比赛机库，驾驶 Supermarine S.6、Gloster VI 或 Macchi M.67 完成三圈海上计时赛，完赛后播放烟花。三架竞速机根据用户参考图和历史照片分别重建机身、翼型、浮筒、支柱与材质。天空采用三维密度体积云，调整大气散射、云内透光及太阳亮度。

## 施耐德纪念赛

驾驶漫游飞机前往珊瑚岛栈桥，进入约165米范围、海拔低于80米时弹出邀请。选择“继续飞行游览”可关闭；离开350米后再次接近可重新邀请。选择“进入比赛机库”后，可查看三架独立比赛飞机的透视、三视图和发动机细节。比赛机型不覆盖漫游机库的选择。

出发后先准备3秒，水面加速起飞；正向穿过A门才开始计时。依次通过 A→B→C→D→A，完成三圈，建议海拔100–220米。每圈约8.6公里；航门只接受当前目标和正确方向，低于45米的穿越不计数。暂停不计时，坠毁中断比赛，R或结束卡片可重赛。本机最佳成绩按飞机分别保存。完赛后播放约19秒烟花，可继续飞行；“结束比赛，继续游览”返回原漫游机型在珊瑚岛的泊位。

此项为游戏内虚构的三圈计时纪念赛，没有AI对手机群，未复刻某届历史赛事。飞机性能采用游戏调校。参考与模型限制见 [竞速飞机参考记录](docs/RACE_REFERENCES.md)。快速检查：`/aircraft.html?race=1&aircraft=s6`；烟花效果预览：`/?fireworks=1&time=dusk`（不记录比赛成绩）。

## 天气与海域

右上角“天气”可选择晴天、多云、阴天、雨天、多雾，通常约 7 秒平滑过渡。手动切换后关闭自动天气；在 H 操作指南中重新勾选“自动变化天气”即可恢复。自动模式仅在实际飞行且未暂停时计时，首次约 3.5 分钟，后续约 3–6 分钟变化一次。暂停时停止自动天气计时与云雨动画。天气影响天空、光照、能见度、海面、表面湿润色和雨声；风力会改变浪高并影响水面接触，当前不会给空中飞行施加阵风。雨声在开始游戏首次解锁音频后播放。

地图使用固定海域种子 `SeaSeed=8033` 保持任务可重放，并在不同方位区域内进行随机采样与安全间距检查，不会在每次刷新时重新洗牌。六岛外缘保持至少约1.45 km间距，海图扩大为12×12 km；港口起飞点保留。

图鉴点击“近岸细看材质”可检查岩壁，例：`/?view=cove&shore=1&weather=sunny`。天气参数可使用 `sunny`、`cloudy`、`overcast`、`rain`、`fog`；网页天气选择器支持即时切换。

## 机库与三种飞行风格

机库（`aircraft.html`）提供三架飞机的模型、驾驶风格和巡航速度比较，可旋转缩放、切换三视图、查看发动机并转动螺旋桨。游戏与机库共用模型。选择会记在本机浏览器，URL 也携带选机信息；存储被禁用时仍可出发。快速连续切换时只显示最后一次选择，旧模型与纹理会释放。

| 飞机 | 参考巡航速度 | 起飞门槛 | 驾驶风格 |
| --- | --- | --- | --- |
| 红翼一号 | 约 210 km/h | 约 90 km/h | 较快转向与俯仰响应，可连续翻滚 |
| M5战斗飞艇 | 约 110 km/h | 约 70 km/h | 转向平缓、速度较低，适合观光 |
| 马基 MC.72 | 约380 km/h | 约140 km/h | 双浮筒竞速机，连续翻滚、筋斗与殷麦曼转向 |

这些是游戏调校值。红翼一号保留朱红单翼、长封闭整流罩与平直尾段。M5 按用户照片制作浅灰色布面双翼、木质船身、白色船底、开放座舱及后推式发动机，约长 8.4 m、翼展 11.9 m。三架模型均保留独立舵面和螺旋桨；三机保留原创贴图、独立PBR材质与几何细节。暂停后可点击“返回机库换机”；新航程按机库选择的起点开始，任务清零。

场景增加分层石灰岩面、内湾岩壁、坡地灌木、伞状松与橄榄树、贴地步道、曲线滨水村落、建筑石基、系船码头与防波堤。港口保留 190 m 宽的水上起降通道。航图、出生点和五航点航线随扩图同步更新，岛间航程更长。

统一太阳方向驱动大气天空、三维云密度、云影、HDR 环境与近/远两级独立打包深度阴影。飞机加入基于实际几何的局部环境遮蔽，烤漆、布面、木材、皮革和金属分别调校。海面包含相位一致的几何涌浪、由地形生成的浅水/泡沫与经过 mip 预过滤和亮度压缩的环境反射。反射混合权重限制在约 2%–20%；海面不叠加级联阴影，不显示飞机自身的近水平面倒影，以避免裁剪及阴影采样伪影。平衡画质关闭实时反射并降低分辨率，保留实时阴影；流畅档进一步降低分辨率并关闭实时阴影。采用实时近似光照；与参考图仍有细节差距。

群岛重新散布于约144 km²海域，松林岛处于内部，其余岛屿方位和间距不同；远景岛也随机分布。保留港口起飞点，边界外仍可自由飞行。

房屋布局分为滨水街道、村落组团和山坡住宅，分别调整体量、朝向与间距。港口66栋、小镇78栋，留出广场、后巷和上山道路；屋檐、阳台的旋转占地进行分离轴检查，道路和建筑地基同步检查。树木会避开房屋、广场和道路。六种模型包括渔屋、带阳台窄楼、三拱骑楼、四坡顶别墅、低矮作坊和非对称露台住宅；近处使用精细实例模型，远处保留各类轮廓代理。

## 飞行操作

| 操作 | 按键 |
| --- | --- |
| 抬头 / 低头 | W / S，或方向键上 / 下 |
| 左 / 右倾斜转弯 | A / D，或方向键左 / 右 |
| 连续翻滚（红翼一号 / MC.72） | 按住空格 + A / D |
| 左 / 右偏航 | Q / E |
| 增加 / 降低油门 | Shift / Ctrl |
| 返回港口并清除挑战 | R |
| 暂停 / 继续 | Esc |
| 展开 / 收起着水指导 | L |
| 切换视角：追尾 → 远距追尾 → 侧方 → 俯瞰 → 驾驶舱 | C，也可点击顶部视角按钮 |
| 打开 / 关闭航图（默认收起） | M 或顶部航图按钮；Esc优先关闭航图 |
| MC.72辅助垂直筋斗 / 殷麦曼转向 | X / Z |
| 反转W/S和上下方向键俯仰（所有飞机，保存设置） | I 或 H指南内勾选 |
| 操作指南、音量和画质 | H |

按住 Shift 加油门，达到当前飞机的起飞门槛后按 W 抬头。起飞后松开 W，飞机会逐渐平飞。红翼一号与MC.72在足够空速下可用空格 + A/D 执行完整 360° 或连续翻滚；松开空格与方向键后自动回正。建议先爬升至 100 m 以上再练习，倒飞会损失升力。M5 对同一组合键保持普通平缓转弯。

着水时先收油门，缓慢下降，在接触海面前回正机翼并松开 S。低速会失去升力，硬着水和主要地形碰撞会中断飞行。失焦后会暂停，需要主动继续。R 重置保留所选机型，并恢复飞机、相机与任务；相机回到默认追尾视角。

游戏内水面降落建议（高度为船底距当前浪面的距离）：

| 飞机 | 建议进近空速 | 开始准备进近 | 最后放平 | 建议接水下降率 |
| --- | --- | --- | --- | --- |
| 红翼一号 | 110–145 km/h | 60–100 m | 最后 5 m | ≤ 1.2 m/s |
| M5战斗飞艇 | 80–105 km/h | 50–80 m | 最后 4 m | ≤ 1.1 m/s |

先选择开阔水面，以 Ctrl 逐渐收油减速，轻点 S 建立缓降。进近下降率建议红翼不超过 2.0 m/s、M5 不超过 1.8 m/s；接近海面后松开 S、轻点 W 放平，机翼尽量水平。速度、姿态或下降率不合适时先调整或复飞；高度低并不表示已经安全。L 面板会显示实时距浪面高度、相对浪面下降率，以及岸线/障碍提示。它是当前游戏参数的建议，不提供自动降落。R 回港会恢复自动提示模式。

在港口附近点击“开始环岛挑战”，依次飞过金色航环：港湾出口、海岸小镇、灯塔外海、返航海面、港口终点。完成后可以继续漫游或再次挑战。暂停和打开指南时不会累计挑战用时。

## 美术资产重建

`art/bake_aircraft_ao.py` 使用 24 条半球射线和 0.9 m 半径生成每顶点局部遮蔽，原模型制作脚本会自动调用；源模型与 GLB 均保留线性遮蔽数据，几何形状不变。运行时遮蔽只作用于间接光，保留太阳和漆面高光。

保留了 `art/aircraft.blend`、`art/m5.blend`、`art/environment.blend` 和制作脚本。使用本机 Blender 运行：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --python art/build_aircraft.py
/Applications/Blender.app/Contents/MacOS/Blender --background --python art/build_m5.py
/Applications/Blender.app/Contents/MacOS/Blender --background --python art/build_environment.py
npm run build
```

其他系统使用对应 Blender 可执行文件路径。红翼视图位于 `art/aircraft_views/`，M5 四视图位于 `art/m5_views/`；原始贴图保留在 `art/textures/` 与 `art/m5_textures/`，同时嵌入 GLB / Blender。环境脚本导出可复用模块，运行时实例化，远处建筑切换简化模型。

## 坐标与参数

- 1 世界单位 = 1 米；世界 Y 向上，飞机局部前向为 -Z、右方为 +X。
- Blender 脚本有意采用同一 Y-up 坐标，GLB 导出关闭额外轴向转换；不要手动再旋转整个模型。
- `src/aircraft/FlightConfig.ts` 分别管理三架飞机的动力学与特技能力；`AircraftCatalog.ts` 管理模型、名称和选机恢复。红翼普通转弯倾角约 52°，M5 约 28°，红翼特技翻滚不受该角度上限限制。
- `src/world/WorldConfig.ts` 定义岛屿位置、尺度、海湾与地形；`src/missions/MissionManager.ts` 定义航线。
- H → 画质：精致 100% 分辨率、实时反射/阴影、35% 体积云；平衡 85%、关闭反射、保留阴影、27% 体积云；流畅 70%、关闭反射/阴影、20% 体积云。三档均保留三维云体。
- 海浪具有实际顶点位移和匹配的解析法线，近岸逐渐衰减；飞机、船只与尾流视觉跟随波面，动力学接触采样同一波面的船体与浮筒位置，并使用相对波面垂直速度判断着水。

## 当前边界

仅支持桌面键盘。当前包含六座可探索岛屿，没有步行、战斗、多人或账号系统。树木不做逐个精细碰撞；移动渔船与主要礁石采用简化碰撞；海域边缘采用雾气和返航提示。声音是原创合成音效，尚非真实发动机和水花录音。模型加载失败会保留程序外形，非关键资产不会阻止启动。

本地工程保留 Git 阶段记录。每次阶段版本都可通过 Git 检出；不要把尚未通过的视觉或兼容性检查视为已完成。

## 昼夜与靠泊

右上角“时刻”可选晨（07:00）、午（12:00）、昏（17:30）、夜（23:00）。游戏默认从正午开始，一天约24分钟；手动选时刻后关闭自动昼夜，H可重新勾选。暂停、帮助和隐藏标签时停止时钟。R返回港口不重置时间。夜间教堂窗户、栈桥灯和灯塔点亮，灯塔两束真实锥体以固定方向旋转；体积密度用射线积分，水面受光跟随同一方向。

机库“起点”可选择港口水域或六岛栈桥。从栈桥出发时已系泊，先按 F 解缆，再加油门。自由航行时先着水，从栈桥外侧靠近，空速低于18 km/h、距泊位35米内按F系泊；系泊清空速度、油门和翻滚，机体继续随波升沉。再次F解缆。系泊会结束正在进行的挑战；R始终返回港口水面。航图小方框表示泊位。

外海栈桥延伸到礁石圈之外，按当前最大机型外廓检查净空，并保留额外余量。靠泊是简化交互，不含绳索动力学或碰撞式泊船模拟。

固定检查地址：`/?view=harbor&church=1&time=morning`、`/?view=lighthouse&time=night`。固定泊位启动可用 `/?aircraft=mc72&berth=coral&launch=1`，也可从机库选择。


## MC.72 模型与调校

结构和尺寸参考用户照片及[意大利空军技术资料](https://www.aeronautica.difesa.it/2022/12/22/macchi-mc72/)，同轴对转结构另参照[ASME工程地标资料](https://www.asme.org/about-asme/engineering-history/landmarks/281-aeronautica-macchi-mc-72-seaplane)。模型翼展9.48m、全长8.32m、总高约3.30m，双浮筒带V形底和断阶，机翼为低置薄翼，黄铜散热面贴合翼型。两组双叶金属桨保留独立节点及相反转向；座舱、排气管、拉索、舵面、红色烤漆和独立清漆层保留。

游戏调校巡航约380km/h，最高限速486km/h，起飞约140km/h，进近建议160–210km/h；这些是本游戏的操控参数，不代表真实飞机极限性能的仿真。高速转弯需提前规划；游戏内开放空格+A/D连续翻滚。辅助特技需海拔至少180m、空速至少306km/h，平飞后按X执行垂直筋斗，按Z执行半筋斗接半滚转，完成反向平飞。特技实际改变轨迹、姿态和空速，仍受碰撞影响，完成后恢复手动操纵。此能力为游戏调校，不作为真实MC.72的飞行能力描述。MC.72建议从距浪面90–140m准备进近，最后7m把相对下降率降至1.1m/s以内。

源文件为art/mc72.blend，重建脚本art/build_mc72.py，原始贴图art/mc72_textures，同源四视图art/mc72_views，运行模型public/models/mc72.glb。可用之前的Blender命令运行该脚本。旧albatross链接及保存记录迁移到mc72；已删除的tern记录安全回退到默认有效机型。历史阶段可从Git恢复，当前静态包不再发布旧机型。

W/S反转默认关闭，按I或H指南内的选项切换，跨机型及刷新保存。反转时S抬头、W低头，上下方向键同步反转，起飞及降落提示也会更新；A/D、Q/E和油门不受影响。特技中可调油门；暂停/失焦会停止飞行更新，R重置会清除特技。


## 航行界面与模型材质

航图由玩家手动打开，初始不占据画面；M可反复打开/关闭，右上角×或Esc可关闭。航图不是暂停菜单，打开时飞行继续。顶部航向刻度跟随机头实际方向变化，显示方位字母和角度；X/Z为本地米制坐标，没有虚构地理经纬度。接近垂直姿态时使用控制器航向，避免刻度在投影长度趋零时抖动。

机库采用左侧机队及资料栏、中央完整模型、底部观察及出发操作。使用与飞行场景一致的便携阴影。全机队保持独立可动舵面与螺旋桨；新增几何静态合批。所有材质先保留GLB贴图，再按物理材质调校，烤漆仍为非金属漆层，未通过把油漆设为纯金属来制造反光。

art/bake_aircraft_ao.py统一处理三机型AO和导出：为退化封口面补平面UV，清除零面积面，三角化大多边形，使GLB法线贴图具备有效切线。三架.blend、制作脚本和运行GLB同步保留。

## v0.26 体验改进

默认采用自动画质，从平衡档开始；持续低帧率5秒后降低一档，恢复画质要求较长时间的性能余量，切换后保留冷却期。H指南可手动选择精致/平衡/流畅，关闭本次自动调节；URL显式quality=high/balanced/performance同样手动锁定。云积分采用40/28/20步，配合各档分辨率减少计算量，保留三维云体。

着水增加沿双浮筒/船体接触点扩散并随浪面浮动的泡沫，约2.2秒消退。M5、船体机与双浮筒机的水花和尾流展开比例不同；着水声音随冲击和速度增强。此轮不改变原有动力学与安全着水阈值。

比赛增加12段用时、每圈成绩及相对个人最佳的累计领先/落后时间。首次完赛会按机型保存完整最佳航迹，下一次起跑穿门后显示淡青线框幽灵；比赛侧栏可关闭。幽灵不参与碰撞与计时判定，只回放个人记录。暂停不推进航迹，R清除当前录制但保留个人最佳。记录保存在本机浏览器，不上传；存储不可用时仅当前页面保留。旧版本只有总成绩，需重新完赛生成航迹。

## v0.27 群岛手册、委托与摄影

飞行中按 J 打开手册，查看六岛角色、到访与靠泊纪念、六项专属委托、空中时间/里程和最近40条带日期的日志。需在出发岛靠泊接取委托，在目的岛靠泊交付；观察任务还需先经过60–250米高度的指定外海观察点。界面提供方向、距离或坐标。一次只能携带一项；R、坠毁、离开页面或换机取消未完成委托。手册打开时冻结飞行和计时。

发现三座岛解锁原创海蓝配色；完成两项委托或首次完赛解锁原创象牙白配色。在手册选择后，红翼一号和MC.72的红色漆面实时改变，机库同步显示；保留原有纹理、高光和金属区别。M5及比赛机型保留原材质。纪念配色是游戏原创，未宣称历史考据复刻。靠泊六岛收集纪念章，码头增加邮袋、长椅、救生圈、补给箱、奖杯和航图等小物。

P进入摄影：冻结物理、计时、云浪与昼夜并隐藏飞行界面。拖动环绕、右键平移、滚轮缩放，WASD平移、Q/E升降，滑块调整25–85度视角；隐藏工具栏后Tab恢复。P/Esc或按钮退出并恢复视角。保存PNG导出当前渲染分辨率的无界面照片至浏览器下载位置，日志记录张数。日志和奖励只保存在当前浏览器；存储不可用时保留本次页面状态。

按机型调整发动机音调/负载滤波，低空港镇有原创合成汽笛或钟声。尚未加入配音、人声或逐机实录音源。

## v0.28 小镇湾口与晨昏天空

海岸小镇港池、湾口和向外进近方向不再散布装饰礁石及其碰撞体，背侧海岸保留自然礁石。两侧石砌防波堤向湾外延伸，保留约596米中央通道；堤头设置小型白色航标塔与红绿灯，夜间增强亮度。栈桥位置及岛间航线保留。

晨间采用浅金直射光和冷蓝高空，日落采用偏橙红直射光与紫色背日天空；色彩受太阳方位与高度共同影响，连续插值至正午及夜晚。云体由32增加到48组，交错布置低碎云、积云、中层云塔、3200–4050米高云和4800–5600米薄云带；上层云置于较远海域，便于海面视角观察。仍采用三维密度积分，自动画质保留。云量增加会提高渲染开销，未承诺持续60FPS。
